1 Find an assistant

Calls GET /api/v1/lsas/search/. Only verified assistants who are accepting bookings appear. This is the endpoint whose N+1 query problem was resolved — it costs the same 3 database queries whether it returns 5 results or 500.

3 Simulate the payment

        

          A new booking sits at PENDING_PAYMENT. In production the payment gateway sends a
          signed webhook to POST /api/v1/payments/webhook/. These buttons sign a real
          event server-side and replay it through that endpoint.
        


        

          
          
        


        

          
          
          
        


        

          Try this: mark a payment succeeded, then press Send the same event twice.
          The second delivery returns duplicate and changes nothing — payment gateways
          resend events, and a replay must never charge or confirm twice.
